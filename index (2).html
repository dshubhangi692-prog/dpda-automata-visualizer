The DPDA behind it (definition + live transition table)

Deterministic: at most one rule for every (state, input, stack-top) combination and no ε-moves. A missing rule is the implicit dead state = reject. · means “any stack symbol, stack untouched”. Brackets inside strings and comments are ignored because in qstr / qline / qblk the machine never looks at the stack – exactly what a real compiler front-end has to do. Bracket structure is a deterministic CFL, so a single left-to-right pass is enough.
